# Lista de Tarefas

## Descrição
Uma aplicação web simples para gerenciar uma lista de tarefas. Permite adicionar, visualizar e gerenciar tarefas de forma intuitiva.

## Tecnologias Utilizadas
- HTML
- CSS
- JavaScript

## Como Usar
1. Abra o arquivo `index.html` em um navegador web.
2. Digite uma tarefa no campo de entrada.
3. Clique em "Adicionar" para incluir a tarefa na lista.
4. As tarefas cadastradas aparecerão na lista abaixo.

## Estrutura do Projeto
- `index.html`: Arquivo principal da aplicação.
- `CSS/style.css`: Estilos da página.
- `JS/script.js`: Lógica JavaScript para funcionalidade da lista de tarefas.

# 🌍 Bandeiras do Mundo

Um projeto web moderno e interativo que exibe informações sobre países do mundo com suas respectivas bandeiras.

## 📋 Características

✅ **Galeria de Bandeiras** - Exibe 50+ países com suas bandeiras  
✅ **Informações Detalhadas** - Nome comum, oficial e nomes nativos  
✅ **Buscas Inteligentes** - Procure por país em tempo real  
✅ **Design Responsivo** - Funciona perfeitamente em qualquer dispositivo  
✅ **Animações Suaves** - Transições e efeitos visuais agradáveis  
✅ **Carregamento Dinâmico** - Dados carregados de arquivo JSON local  

## 📁 Estrutura do Projeto

```
AV1-RAPHAELA/
├── index.html           # Página principal
├── css/
│   └── style.css       # Estilos personalizados
├── js/
│   └── script.js       # Lógica JavaScript
├── data/
│   └── countries.json  # Dados dos países
└── README.md           # Este arquivo
```

## 🚀 Como Usar

1. Abra o arquivo `index.html` em um navegador web
2. Aguarde o carregamento da lista de países
3. Use a barra de busca para procurar um país específico
4. Clique em um país para ver mais informações

## 📊 Dados Disponíveis

Cada país possui:
- **Bandeira (PNG e SVG)**
- **Nome Comum** (em inglês)
- **Nome Oficial**
- **Nome Nativo** (quando disponível)
- **Descrição da Bandeira**

## 💻 Tecnologias Utilizadas

- **HTML5** - Estrutura
- **CSS3** - Estilos e animações
- **JavaScript (ES6)** - Interatividade e dinâmica
- **Bootstrap 5** - Framework CSS
- **JSON** - Armazenamento de dados

## 🎨 Design

- **Paleta de Cores**: Gradiente roxa a azul
- **Tipografia**: Segoe UI, Verdana
- **Layout**: Grid responsivo
- **Animações**: Fade-in, hover effects

## 📱 Responsividade

O projeto é totalmente responsivo:
- **Desktop** (≥992px): 4 colunas
- **Tablet** (768px-991px): 3 colunas  
- **Smartphone** (<768px): 2 colunas

## 🔍 Funcionalidade de Busca

- Busca em tempo real conforme você digita
- Busca por nome comum ou oficial
- Case-insensitive
- Mostra mensagem quando nenhum resultado é encontrado
